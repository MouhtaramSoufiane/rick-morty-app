##  Getting Started

###  Prerequisites

Before getting started with rick-morty-app, ensure your runtime environment meets the following requirements:

- **Programming Language:** JavaScript
- **Package Manager:** Npm > 8
- **Node JS:** node > 18

#### Check npm version

```sh
❯ npm -v
```

#### Check nodejs version

```sh
❯ node -v
```

###  Installation

Install rick-morty-app using one of the following methods:

**Build from source:**

1. Clone the rick-morty-app repository:
```sh
❯ git clone https://github.com/MouhtaramSoufiane/rick-morty-app
```

2. Navigate to the project directory:
```sh
❯ cd test-tec
```

3. Install the project dependencies:


**Using `npm`** &nbsp; [<img align="center" src="https://img.shields.io/badge/npm-CB3837.svg?style={badge_style}&logo=npm&logoColor=white" />](https://www.npmjs.com/)

```sh
❯ npm i
```




###  Usage
Run rick-morty-app using the following command:
**Using `npm`** &nbsp; [<img align="center" src="https://img.shields.io/badge/npm-CB3837.svg?style={badge_style}&logo=npm&logoColor=white" />](https://www.npmjs.com/)

```sh
❯ npm run dev
```

##  Project Roadmap

- [ ] **`Configurer l'API Rick & Morty`**: Créer un service pour interagir avec l'API Rick & Morty.
- [ ] **`Récupérer les données des personnages`**: Tester la récupération des données des personnages depuis l'API.
- [ ] **`Création de la page des personnages`**:
  - [ ] Lister tous les personnages avec leurs informations pertinentes (nom, statut, espèce, genre, image).
  - [ ] Mettre en place la pagination pour afficher les personnages par pages.
  - [ ] Ajouter une barre de recherche pour filtrer les personnages par nom.
  - [ ] Implémenter un système de filtrage par statut, espèce et genre.
- [ ] **`Page de détails des personnages`**:
  - [ ] Créer une page dédiée pour afficher les détails d'un personnage spécifique.
  - [ ] Afficher les informations complètes du personnage (nom, statut, espèce, genre, image, etc.).
  - [ ] Ajouter un bouton pour ajouter le personnage aux favoris.
- [ ] **`Page des personnages favoris`**:
  - [ ] Créer une page qui affiche uniquement les personnages ajoutés aux favoris.
  - [ ] Assurer la gestion des favoris (ajout, suppression).
  - [ ] Permettre aux utilisateurs de naviguer facilement entre les favoris et la liste complète.
